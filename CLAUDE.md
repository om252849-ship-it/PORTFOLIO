# Om Kumar — Portfolio & Resume (App Directory)

This is the Next.js web application for **Om Kumar's Portfolio & Interactive Resume**.

- **Dev Server**: `npm run dev` (Runs on `http://localhost:3000`)
- **Build**: `npm run build`
- **Lint**: `npm run lint`

## Resume & Content Source of Truth
- `data/content.json` holds all data (Bio, Experience, Education, Skills, Projects, Contact).
- Any edit here updates both the homepage and the `/resume` page automatically!
